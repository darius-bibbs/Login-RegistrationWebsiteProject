# GeeksGalore Gaming Website

GeeksGalore is a clean, responsive front-end concept for a gaming products and services website. It currently focuses on the user authentication experience, featuring a full-screen gaming background with modal login and signup forms.

## Features

- Responsive navigation header
- Login modal with email and password fields
- Signup form with password confirmation fields
- Login and signup form switching
- Show/hide password controls
- Remember-me checkbox
- Forgot-password link placeholder
- Gaming-themed full-screen background
- Smooth modal transitions and interactive styling
- Unicons for interface icons

## Built With

- HTML5
- CSS3
- Vanilla JavaScript
- [Unicons](https://iconscout.com/unicons)
- [Google Fonts - Poppins](https://fonts.google.com/specimen/Poppins)

## Getting Started

1. Clone or download this repository.
2. Make sure the background image referenced in `style.css` is available as `8kpc.jpg` in the project folder.
3. Open `index.html` in a web browser.

No build tools or dependencies are required.

## Project Structure

```text
.
├── index.html    # Page structure and authentication forms
├── style.css     # Layout, theme, and responsive styling
├── script.js     # Modal, form switching, and password visibility behavior
└── 8kpc.jpg      # Background image referenced by the stylesheet
```

## Current Scope

This is a front-end prototype. The login and signup forms are visual and interactive only; they do not currently connect to a database, authentication service, or backend API. The navigation links and forgot-password link are also placeholders for future pages and functionality.

## Future Improvements
